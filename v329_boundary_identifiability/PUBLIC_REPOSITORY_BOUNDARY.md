# Public Repository Boundary

Included: deterministic code, configuration, source registries, author-derived
coding ledgers, derived tables, generated figures, runbook and citation metadata.

Excluded: article PDFs, active manuscript and submission PDFs, cover letters,
reviewer-response drafts, internal model-review rounds, credentials, portal
records, private author/funding records and third-party files without confirmed
redistribution rights.

The package supports reproducibility and traceability. It does not certify the
validity or performance of a lunar-construction route.
